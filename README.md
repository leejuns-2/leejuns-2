## Selected Projects

### [Energy Report-to-Market Signal Analyzer](https://github.com/leejuns-2/DL_project)

Evidence-grounded analysis pipeline for energy and climate reports using document retrieval, MiniLM embeddings, topic classification, and Gemini-based summarization.

- Compared zero-shot embedding similarity with a supervised linear probe
- Evaluated the pipeline on a 50-document development set
- Analyzed failure cases and limitations of retrieval, classification, and generated summaries

### [Seoul Tourism Visitor Forecast](https://github.com/leejuns-2/tourist-forecast)

Machine learning course project for forecasting daily visitor counts at Seoul tourism locations.

- 3-person team project
- Responsible for the regression modeling track
- Compared multiple regression models using time-based train/validation/test splits
- Conducted feature ablation and prediction error analysis

### [Satellite Segmentation Learning Lab](https://github.com/leejuns-2/knps_satellite_ai_learning)

Learning repository for PyTorch-based semantic segmentation and geospatial image processing.

- Implemented a small U-Net style segmentation pipeline
- Practiced Dice/IoU/Precision/Recall evaluation
- Explored GeoTIFF handling and image-mask alignment
- Current experiments are primarily based on synthetic data

## Other Project

### [Recovery Priority AX](https://github.com/leejuns-2/recovery-project)

Machine-learning project for prioritizing areas that may require closer post-flood recovery monitoring using event-wise evaluation and XGBoost.
